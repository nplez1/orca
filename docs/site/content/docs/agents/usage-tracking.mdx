Orca reads local usage state for Claude Code, Codex, Gemini, OpenCode, Kimi Code, and MiniMax and surfaces it in the status bar, so you know how close you are to a rate limit before an agent stalls.

## What's shown

- Current usage against the active account's plan.
- Time to reset for 5-hour, daily, weekly, and Claude Fable weekly windows (where applicable).
- A warning chip when you cross 80% of a limit.
- A monthly allowance bar for enterprise and usage-billed plans, which report a spending ceiling instead of 5-hour and 7-day windows.

## How it works

Orca reads the local usage state each agent maintains on disk (under `~/.claude`, `~/.codex`, and the Gemini/OpenCode equivalents). No API calls, no extra auth. This means the readout is only as fresh as the agent's own bookkeeping — numbers update when the agent writes, not in real time.

GitHub Copilot is the exception, because Copilot is not a CLI agent on disk. Orca reads the Copilot entitlement GitHub tracks for you through the **GitHub CLI** sign-in you already have, so no separate token is involved. **Settings → Accounts** runs the exact `gh` command inline when that sign-in cannot serve the read.

<Callout title="GitHub Copilot sign-in">
  The entitlement read needs the ordinary `user` scope. **Settings → Accounts** reports the state of
  that sign-in and runs the command that fixes it: `gh auth refresh -s user` for a missing scope,
  `gh auth login` when nothing is signed in. When `gh` is not installed there is no command to run,
  so that section shows install guidance instead.
</Callout>

## Multi-account accounting

The status bar always reflects the _active_ account. Other configured accounts are visible in the account switcher with their own usage.

## Usage roster

Click the usage segment in the status bar to open the **Usage** popover. It lists every tracked provider (icon · name · plan · soonest reset · per-window bars), sorted so the tightest limit is first. Use the header refresh control to re-read local usage state.

- **Detailed** — full bars, labels, and percentages for every window
- **Compact** — only the tightest window per provider

Under [Settings → Appearance](/docs/settings), choose **% used** vs **% remaining** for how those numbers read.

Rows without live numbers show a short status instead: **Loading usage…**, **not signed in**, **Usage unavailable**, **No usage data**, or a provider-specific error. Claude and Codex rows can drill into account switching; **Manage accounts** opens Settings.

### Mobile

On the companion app, open the host **Accounts** screen for the same switcher/usage readout. When Codex has earned **rate-limit reset** credits, spend one from that screen (see [Mobile companion](/docs/mobile)).

## Enterprise and usage-billed plans

Some plans report a spending ceiling rather than 5-hour and 7-day quota windows. When the active account reports no such window, Orca shows the ceiling's own percentage as a monthly bar, and the detail panel shows the amounts consumed against it.

- **GitHub Copilot** — the premium-interaction credits consumed this month against your Copilot entitlement, e.g. `412,300 of 1,000,000 AI credits`. GitHub reports that entitlement per user, so the readout follows whichever account your **GitHub CLI** is signed in to. Nothing is stored in Orca: the CLI's own sign-in is the credential.

  When the sign-in cannot serve the read, **Settings → Accounts** shows the exact command to fix it — `gh auth login` when `gh` is installed but signed out, or `gh auth refresh -s user` when the sign-in is missing the scope — and runs it in an inline terminal. When `gh` is not installed at all, that section says so and leaves the terminal out.

GitHub Copilot is also the exception to how the percentage is read: Orca normally shows the figure the provider itself reports, but GitHub reports only the credits consumed and the entitlement they count against, so Orca derives the percentage from those.

## Estimated cost (Stats)

The Stats breakdown may show **estimated cost** for known model families (including Claude 5-class and Codex GPT-5.6 rows). Rows marked **• inferred pricing** use Orca’s local price table, not a live bill from the provider. Prefer the provider console for authoritative spend.
